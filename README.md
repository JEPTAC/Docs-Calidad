# Word Studio Pro · capa aditiva

Esta extensión se carga sobre la maqueta institucional original del commit b01b8005. No sustituye el HTML base ni modifica sus márgenes, encabezado, intro o módulos existentes. Añade únicamente bloques avanzados de Word, jerarquía de subtítulos niveles 2–6, tablas, gráficas, KPI, notas, citas, referencias, imágenes, listas, paginación y exportación DOCX.
